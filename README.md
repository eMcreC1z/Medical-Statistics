## 贯穿全仓库的原则

医学统计学不是“选择一个检验”的技术目录，而是围绕明确科学问题组织证据的全过程。最关键的次序是：

**问题与决策场景 → 目标人群与估计目标 → 研究设计 → 暴露和结局测量 → 数据结构诊断 → 主分析 → 敏感性分析与三角验证 → 因果解释边界 → 临床或公共卫生转化。**

复杂模型不能修复不恰当的研究设计、错误的时间顺序、严重测量偏倚或未被识别的选择机制。方法越灵活，越需要明确假设、验证稳定性并限制解释范围。
