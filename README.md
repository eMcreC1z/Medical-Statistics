## 贯穿全仓库的原则

医学统计学和数据科学不是“选择一个检验或算法”的技术目录，而是围绕明确科学问题组织证据的全过程。最关键的次序是：

**问题与决策场景 → 目标人群与 estimand → 研究设计与数据生成机制 → 暴露和结局测量 → 数据与时间审计 → 主分析 → 诊断、敏感性与三角验证 → 因果或预测解释边界 → 临床/公共卫生决策 → 部署监测与更新。**

复杂模型不能修复不恰当的研究设计、错误时间零点、严重测量偏倚、未识别选择机制或信息泄漏。方法越灵活，越需要明确假定、验证稳定性并限制解释范围。软件运行成功也不等于分析有效；warning、收敛、变量编码、重抽样单位、时间边界、数据版本、模型选择和计算环境都属于证据链。

统计学精通的最低标准，不是记住更多函数，而是能够说明：

1. 数据为何以当前方式产生；
2. 希望估计、预测或决定什么；
3. 模型为何与设计和 estimand 一致；
4. 近似、先验或算法依赖哪些条件；
5. 代码如何重建结果；
6. 诊断、模拟和外部验证允许结论延伸到什么范围；
7. 方法失败时应重新估计、重新定义参数还是重新设计研究。

## 来源与版本说明

- Gordis 学习材料为中文译稿合订本，文件自身说明原书图像未重绘或嵌入，适合内部学习和术语统一。
- 环境混合物材料为 2025 年著作的中文翻译版，个别位置存在排版、断行或译文缺漏；仓库按上下文和全书结构提炼，不对缺失原文作无依据补写。
- 《医学统计学》第 7 版出版于 2018 年，共 15 章；纸质教材附 SPSS 17 上机实习并配有 SPSS、SAS 资源。
- 《医学统计学》第 8 版出版于 2024 年，共 15 章；保留本科教学主干，增加质量控制图和综合案例，重组研究设计章，并将 SAS、SPSS、R 视频及数据文件纳入数字资源。
- 《医学统计分析与 R 语言》说明其代码在 R 3.2、Linux Mint 17.2 环境下测试；安装命令、包接口和 warning 示例均按源书时代代码审读。
- 《统计学——基于 R（第 3 版）》上传文件为 2019 年扫描版，文字层不可检索；笔记以可辨认的前言、目录、图表和示例页为依据。
- 《R 语言实战（第 2 版）》英文版形成于 2015 年、中文版出版于 2016 年；其工作流仍有价值，具体包、默认值和动态报告工具需按当前 R 环境复核。
- 《时间序列分析与 R 软件》为 2020 年扫描版教材；笔记保留理论—案例—R 实现结构，对不清晰符号和代码不作臆测复原。
- *Time Series Analysis: Forecasting and Control* 第 5 版中文译本保留经典 Box–Jenkins、转换函数、干预和控制框架；R 接口和现代验证要求另作扩展标记。
- 《时间序列分析实战》英文版出版于 2020 年、中文版出版于 2022 年，覆盖 Python 与 R；具体深度学习和工具包接口属于时代实现，实际项目需重新核验。
- *Asymptotic Statistics* 初版于 1998 年，数学层次为高年级本科至研究生；严格学习需要多元微积分、概率、测度、度量/赋范空间与 Hilbert 空间基础。
- 《统计推断》与《贝叶斯统计学》上传文件均为图像扫描版；相应笔记以可辨认目录、页面和经典主线为依据，不对模糊公式、定理编号或数值逐字恢复。
- Press 的原著形成于 1989 年、中文译本出版于 1992 年；原书重视数值积分和 Monte Carlo，MCMC/HMC、SBC、LOO 等均在笔记中明确标为现代扩展。
- 《数据挖掘与 R 语言》中文扫描版反映 2010 年代初期 R、MySQL 和 DMwR 生态；案例结构予以保留，现代 pipeline、校准、MLOps 和公平性内容另作扩展。
