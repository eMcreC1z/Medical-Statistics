# Medical Statistics｜医学统计学学习笔记

本仓库用于沉淀医学统计学、流行病学、R 语言分析与复杂暴露方法的学习笔记。当前内容依据四份材料进行独立提炼、重组和方法学审读：

1. David D. Celentano、Moyses Szklo：**Gordis Epidemiology（第六版中文译稿合订本）**。
2. Andrea Bellavia：**Statistical Methods for Environmental Mixtures: An Introduction for Environmental Epidemiology（中文翻译版）**。
3. 李康、贺佳主编：**《医学统计学》第 8 版**。
4. 梁雪枫：**《医学统计分析与 R 语言》**。

> 仓库文件是学习性摘要、方法整合与代码审读，不替代原书，不复制原书大段文字。涉及定义、公式、软件接口和实证结论时，应结合原始文献、研究方案与项目实际环境核对。

## 建议阅读顺序

1. 先读第 3 份整合笔记，建立“问题—设计—估计—解释”的全局框架。
2. 读第 4 份笔记，系统复习医学统计学的基础指标、经典方法和应用条件。
3. 读第 1 份 Gordis 笔记，将统计方法放回流行病学设计、偏倚和因果解释中。
4. 读第 5 份 R 笔记，把方法转化为数据操作、模型诊断和可复现工作流。
5. 使用第 6 份对照表开展具体研究的分析设计和 SAP 核对。
6. 面对高相关、多暴露、非线性和交互问题时，再进入第 2 份环境混合物笔记。

## 贯穿全仓库的原则

医学统计学不是“选择一个检验”的技术目录，而是围绕明确科学问题组织证据的全过程。最关键的次序是：

**问题与决策场景 → 目标人群与估计目标 → 研究设计 → 暴露和结局测量 → 数据结构诊断 → 主分析 → 敏感性分析与三角验证 → 因果解释边界 → 临床或公共卫生转化。**

复杂模型不能修复不恰当的研究设计、错误的时间顺序、严重测量偏倚或未被识别的选择机制。方法越灵活，越需要明确假定、验证稳定性并限制解释范围。软件运行成功也不等于统计分析有效；warning、收敛、变量编码、重抽样单位和软件版本都属于分析证据链。
