# 时间序列模型诊断、预测评价与 R 实现对照表

## 0. 使用说明

本文件将《时间序列分析与 R 软件》和 *Time Series Analysis: Forecasting and Control* 第 5 版中的模型建立逻辑整理为操作型对照表。它用于研究方案、统计分析计划、R 代码审查和论文审稿，而不是替代两本教材的理论推导。

> **版本边界**：表中 R 函数主要对应教材时代的 base R、`stats`、`TSA` 及相关实现路径。函数接口、扩展包维护状态和默认值在实际项目中必须重新核验。保持不变的是分析逻辑，不是某个软件调用。

## 1. 总体工作流

| 阶段 | 核心问题 | 主要产出 | 不能省略的核查 |
|---|---|---|---|
| 任务定义 | 描述、预测、干预、动态输入、多变量还是控制 | estimand、预测步长、干预效应形式 | 目标不能只写“建立时间序列模型” |
| 数据审计 | 时间戳、频率、缺失、分母、制度变化是否可靠 | 时间数据字典、事件时间线 | 不规则间隔不能直接假装规则 |
| 探索 | 趋势、季节、周期、异常、方差如何变化 | 原始图、季节图、分解、ACF/PACF | 图形必须覆盖完整研究期 |
| 平稳化 | 需要何种变换、趋势处理和差分 | 变换与差分规则 | 防止差分不足和过度差分 |
| 识别 | 哪些低阶模型与理论图形相容 | 候选模型集合 | ACF/PACF 不给出唯一模型 |
| 估计 | 参数能否稳定估计 | 系数、标准误、创新方差 | 收敛、根、边界和参数相关 |
| 诊断 | 剩余是否近似创新白噪声 | 残差图、残差 ACF、联合检验 | 不能只报告一个 P 值 |
| 比较 | 哪个模型对任务最合适 | 模型选择说明 | 训练拟合不等于预测性能 |
| 验证 | 新时间段表现如何 | 滚动预测误差、区间覆盖 | 必须保持时间顺序 |
| 报告与监督 | 模型何时失效、如何更新 | 可复现报告、更新规则 | 参数和数据制度会漂移 |

## 2. 时间数据审计表

| 项目 | 必答问题 | 常见风险 |
|---|---|---|
| 时间单位 | 每条记录代表日、周、月、季度还是不规则事件时间？ | 把区间累计当作瞬时值 |
| 频率 | 每年有多少个理论观测？ | `frequency` 与真实周期不一致 |
| 起止时点 | 起点和终点由何种机制决定？ | 截断于异常高峰造成选择性历史 |
| 时间戳 | 是否重复、缺失、错位或时区不一致？ | 重复日期被当作独立观测 |
| 聚合 | 日数据如何汇总为周/月？ | 不同月份天数和暴露量未处理 |
| 分母 | 人口、检测数、床位数、人时是否变化？ | 用计数代替风险或率 |
| 数据修订 | 近期值是否会补报或回填？ | 用最终值评价实时预测 |
| 制度变化 | 编码、检测、仪器和报告规则何时改变？ | 把制度变化当作疾病变化 |
| 干预 | 实施日期、覆盖强度和延迟是否明确？ | 把宣布日期当作实际生效日期 |
| 外部事件 | 是否有同步政策、疫情、灾害或节假日变化？ | 干预效应与共同冲击混淆 |

## 3. 变换与平稳化决策

| 观察特征 | 可能处理 | 诊断依据 | 风险 |
|---|---|---|---|
| 水平越高，波动幅度越大 | 对数或其他方差稳定化变换 | 均值—方差关系、残差图 | 反变换偏差和零值问题 |
| 明显确定性趋势 | 时间趋势、多项式或结构分量 | 趋势图、领域机制 | 高阶多项式外推不稳定 |
| 随机游走式趋势 | 普通差分 \((1-B)^d\) | 缓慢衰减 ACF、单位根证据 | 过度差分增加方差 |
| 固定季节均值 | 季节虚拟变量、正弦/余弦 | 稳定季节图 | 参数多、季节变化时失配 |
| 随机季节持续 | 季节差分 \((1-B^s)^D\)、季节 ARIMA | 季节滞后 ACF | 季节过差分 |
| 水平突变 | 干预阶跃或分段模型 | 已知制度/政策时间 | 与单位根混淆 |
| 暂时冲击 | 脉冲/衰减干预项 | 事件时间线、残差传播 | 机械删除损失机制信息 |
| 方差聚集 | ARCH/GARCH 或稳健处理 | 残差平方 ACF | 误把方差动态当均值动态 |

### 3.1 差分后的快速核查

- 差分后均值应大致稳定；
- ACF 不应继续长期缓慢衰减；
- 一阶 ACF 若接近强负值，应怀疑过度差分；
- 季节峰仍存在时考虑季节差分或季节 ARMA；
- 差分后仍有结构突变时，增加差分阶数通常不是正确答案。

## 4. ARMA 识别对照表

| 候选模型 | 理论 ACF | 理论 PACF | 常见有限样本偏离 |
|---|---|---|---|
| AR(1) | 几何衰减；负参数时正负交替 | 1 阶后截尾 | 接近 1 时衰减很慢，似非平稳 |
| AR(2) | 指数衰减或阻尼振荡 | 2 阶后截尾 | 根接近时可能表现为长周期 |
| AR(\(p\)) | 拖尾 | \(p\) 阶后截尾 | 高阶样本 PACF 噪声较大 |
| MA(1) | 1 阶后截尾 | 拖尾 | 参数接近不可逆边界时图形异常 |
| MA(\(q\)) | \(q\) 阶后截尾 | 拖尾 | 小样本中“截尾”并不整齐 |
| ARMA(\(p,q\)) | 拖尾 | 拖尾 | AR/MA 抵消导致图形近似低阶 |
| 季节 AR | 季节倍数滞后 PACF 特征 | 视结构而定 | 同时存在普通结构时峰形混合 |
| 季节 MA | 季节倍数滞后 ACF 特征 | 视结构而定 | 季节差分会改变峰值形态 |

### 4.1 识别原则

1. 只在近似平稳序列上使用理论截尾/拖尾规则；
2. 优先建立少量低阶候选，而非穷举所有组合；
3. ACF/PACF、信息准则、参数稳定和残差诊断必须联合使用；
4. 异常值和结构突变可制造虚假高阶相关；
5. 模型识别属于探索阶段，最终不确定性应在验证中体现。

## 5. 参数估计与数值核查

| 核查项 | 需要记录 | 异常信号 | 处理方向 |
|---|---|---|---|
| 估计方法 | 条件/精确似然、CSS、ML 等 | 不同方法结果差异很大 | 检查初始状态和边界 |
| 收敛 | 优化状态、warning | 未收敛、梯度大 | 改初值、简化模型、重参数化 |
| 平稳性 | AR 根 | 根位于或接近单位圆 | 重新考虑差分或阶数 |
| 可逆性 | MA 根 | 根接近单位圆 | 检查过度差分和等价参数化 |
| 参数标准误 | 估计值与 SE | SE 极大、符号不稳定 | 识别不足、参数共线或样本过短 |
| 参数相关 | 协方差/相关矩阵 | AR 与 MA 高度相关 | 近似抵消，考虑降阶 |
| 创新方差 | \(\hat\sigma_a^2\) | 降阶后几乎不变 | 复杂项信息增量有限 |
| 初值敏感性 | 多组初值 | 不同局部解 | 报告敏感性并限制解释 |
| 样本长度 | 有效观测与参数数 | 参数相对过多 | 缩小候选集合 |

参数“显著”并不能代替模型充分性；参数“不显著”也不能脱离整体重拟合直接删除。

## 6. 残差诊断对照表

| 诊断 | 目标 | R 实现路径 | 失败表现 | 可能原因 |
|---|---|---|---|---|
| 残差时序图 | 均值稳定、无系统模式 | `plot(residuals(fit))` | 趋势、水平跳变、周期 | 均值结构遗漏、参数漂移 |
| 残差 ACF | 无剩余线性相关 | `acf(residuals(fit))` | 特定滞后尖峰 | AR/MA/季节项遗漏 |
| 残差 PACF | 定位剩余 AR 结构 | `pacf(residuals(fit))` | 前若干阶显著 | AR 阶数不足 |
| Ljung-Box | 联合检验多阶自相关 | `Box.test(..., type="Ljung-Box")` | P 值小 | 欠拟合、滞后选择、异常值 |
| 残差平方 ACF | 条件异方差 | `acf(res^2)` | 波动聚集 | ARCH/GARCH、结构改变 |
| QQ 图 | 重尾与极端误差 | `qqnorm()`、`qqline()` | 尾部偏离 | 异常值、非高斯创新 |
| 直方图 | 分布形态 | `hist(res)` | 偏态、多峰 | 变换不足、混合机制 |
| 累积/滚动误差 | 参数稳定 | 滚动均值、CUSUM 思想 | 长期单向偏差 | 参数漂移、制度变化 |
| 样本外残差 | 真实预测充分性 | 滚动起点预测 | 测试期系统失效 | 过拟合、数据制度改变 |

### 6.1 Ljung-Box 报告最低要求

- 使用的最大滞后 \(L\)；
- 数据频率和季节周期；
- 是否对模型参数数目修正自由度；
- 检验对象为创新残差；
- 同时展示残差 ACF，而非只给 P 值。

### 6.2 正态性的位置

残差正态主要影响精确小样本区间和尾部概率。对于均值预测，残差独立、均值结构正确和方差稳定通常比轻微正态偏离更重要；若关注极端风险，则重尾必须专门建模。

## 7. 季节模型核查

| 问题 | 诊断 | 处理 |
|---|---|---|
| 季节周期是否正确 | 业务日历、季节图、谱峰 | 明确 \(s\)，不依赖默认频率 |
| 季节振幅是否随水平变化 | 不同年份季节图 | 乘法结构或对数变换 |
| 季节模式是否固定 | 分年/分阶段季节图 | 随机季节或时变结构 |
| 是否需要季节差分 | 季节滞后 ACF、季节单位根证据 | 低阶 \(D\)，防止过差分 |
| 普通与季节项是否混淆 | 近滞后和季节滞后联合图形 | 乘积 SARIMA 候选 |
| 节假日是否漂移 | 日历核查 | 显式节假日/工作日变量 |
| 月份长度是否变化 | 聚合规则与分母 | 率、offset 或日均标准化 |

## 8. 预测评价对照表

| 评价对象 | 推荐做法 | 不恰当做法 |
|---|---|---|
| 数据划分 | 最后时段留出、滚动起点 | 随机打乱时间点 |
| 多步预测 | 按 \(h\) 分层报告 | 只给一个总体 RMSE |
| 基线 | 最近值、季节最近值、漂移、简单平滑 | 只比较复杂模型之间 |
| 点预测 | MAE、RMSE、偏差等 | 只看训练期 \(R^2\) |
| 区间预测 | 覆盖率、宽度、尾部失配 | 只展示区间、不检验覆盖 |
| 变换 | 在原尺度评价并说明反变换 | 只在对数尺度报告业务误差 |
| 模型选择 | 选择过程嵌入训练窗 | 用完整数据定阶后评价“测试集” |
| 预测更新 | 明确是否滚动重估 | 测试期偷偷使用未来参数 |
| 决策损失 | 结合低估/高估代价 | 默认对称平方损失 |
| 稳定性 | 分时期、分季节评价 | 只报告总体平均值 |

### 8.1 预测区间

预测区间至少包含：

- 未来创新不确定性；
- 多步误差累积；
- 必要时的参数估计不确定性；
- 变换回原尺度后的不对称性。

区间覆盖不足时，不能仅通过加宽图形阴影解决，必须检查模型错设、创新分布和参数漂移。

## 9. 干预分析对照表

| 干预形态 | 指示变量/动态形式 | 参数含义 | 主要风险 |
|---|---|---|---|
| 脉冲 | \(I(t=T_0)\) | 单时点异常改变 | 数据错误与真实事件混淆 |
| 阶跃 | \(I(t\ge T_0)\) | 持续水平变化 | 同期制度改变 |
| 斜率改变 | \((t-T_0)_+\) | 长期趋势差异 | 干预前趋势外推失败 |
| 延迟效应 | \(B^b I_t\) | 延迟 \(b\) 后开始 | 事后选择最佳延迟 |
| 渐进/衰减 | \(\omega(B)/\delta(B)\) | 动态响应路径 | 参数过多、可辨识不足 |
| 暂时效应 | 脉冲经衰减滤波 | 短期后回归基线 | 随访不足无法观察衰减 |

### 9.1 最低诊断

- 干预前模型能否合理外推；
- 干预后残差是否仍有系统结构；
- 季节性与干预时点是否混淆；
- 是否存在预期效应和实施延迟；
- 是否有安慰剂时点或对照序列；
- 不同干预响应形式下结论是否稳定。

显著干预参数不自动等于因果效应。

## 10. 转换函数对照表

典型模型：

\[
Y_t=\frac{\omega(B)B^b}{\delta(B)}X_t+N_t.
\]

| 阶段 | 任务 | 失败风险 |
|---|---|---|
| 输入建模 | 为 \(X_t\) 建立 ARIMA 并预白化 | 输入自身自相关制造伪互相关 |
| 同步滤波 | 用同一滤波器处理 \(Y_t\) | 输入输出处理不一致 |
| 互相关识别 | 识别延迟 \(b\) 和响应形态 | 多重滞后搜索导致选择偏倚 |
| 噪声建模 | 对 \(N_t\) 建立 ARIMA | 把剩余趋势归因于输入 |
| 联合估计 | 同时估计动态输入和噪声 | 分步估计忽略协方差 |
| 诊断 | 检查残差及与输入的剩余相关 | 模型仍遗漏动态输入 |
| 解释 | 报告冲击响应/累计响应 | 把预测相关解释为因果 |

多个输入高度相关时，需要联合建模和稳定性分析，不能通过分别拟合后比较 P 值来识别“最重要输入”。

## 11. 异常值与缺失值对照表

| 问题 | 模型含义 | 不推荐做法 | 推荐核查 |
|---|---|---|---|
| 附加异常值 AO | 观测局部污染 | 自动删除整行 | 原始记录、局部异常项 |
| 新息异常值 IO | 冲击进入系统并传播 | 只替换该时点值 | 后续动态是否符合模型 |
| 水平改变 | 机制持续变化 | 当作多个离群点删除 | 干预阶跃、制度时间线 |
| 缺失时点 | 状态未观测 | 编码为 0 | 缺失原因、状态空间估计 |
| 连续缺失区段 | 信息断层 | 长区段线性插值 | 预测区间扩大、敏感性分析 |
| 补报/修订 | 当时信息不完整 | 用最终值做实时验证 | 保存历史快照/vintage |

## 12. 多元模型核查

| 模型 | 用途 | 主要假定/风险 | 最低核查 |
|---|---|---|---|
| VAR | 多变量过去值联合预测 | 参数数迅速增加 | 阶数、稳定根、残差互相关 |
| VMA | 创新冲击传播 | 识别与估计困难 | 可逆性、创新协方差 |
| VARMA | 简约联合动态 | 非唯一性和可辨识性 | 模型规范、不同初值 |
| VECM/协整 | 非平稳变量的长期均衡 | 协整秩与趋势设定敏感 | 单位根、秩、长期关系 |
| 状态空间 | 潜在状态、缺失、多源观测 | 状态和参数可辨识 | 滤波创新、平滑不确定性 |

多元模型中的“先行变量”或交叉滞后不等于因果方向。

## 13. 过程监督与控制对照表

| 概念 | 目标 | 风险 |
|---|---|---|
| 过程监督 | 发现特殊原因或参数漂移 | 把自然波动误报为异常 |
| 反馈控制 | 根据输出误差调整输入 | 延迟和噪声导致振荡 |
| 前馈控制 | 根据可提前观测的扰动预调 | 转换函数错设放大误差 |
| 前馈-反馈 | 同时利用扰动与输出 | 复杂度和参数监督需求增加 |
| 有界调整 | 平衡偏差与固定调整成本 | 阈值设定不合理 |
| 采样间隔 | 决定可观测动态与成本 | 过密采样促成过度调整 |
| 参数监督 | 检查控制模型是否漂移 | 固定规则长期失效 |

对稳定过程逐点纠偏可能增加方差，这正是过度调整问题。

## 14. R 函数与统计任务对照

| 统计任务 | 教材时代常见函数 | 关键参数/对象 | 审查重点 |
|---|---|---|---|
| 建立规则序列 | `ts()` | `start`, `end`, `frequency` | 是否丢失真实日期和缺失间隔 |
| 绘制序列 | `plot.ts()`, `ts.plot()` | 时间轴、单位 | 是否截断坐标或遗漏干预标记 |
| 分解 | `decompose()`, `stl()` | 加法/乘法、`s.window` | 季节是否固定、端点效应 |
| ACF/PACF | `acf()`, `pacf()` | `lag.max`, `na.action` | 在何种序列上计算 |
| 周期结构 | `spectrum()` 等 | 去趋势、平滑 | 谱峰不等于机制证据 |
| ARIMA 模拟 | `arima.sim()` | `model`, `n` | 符号约定、随机种子 |
| ARIMA 拟合 | `arima()` | `order`, `seasonal`, `method` | 阶数顺序、截距/漂移、收敛 |
| 白噪声检验 | `Box.test()` | `lag`, `type`, `fitdf` | 自由度和滞后选择 |
| 指数平滑 | `HoltWinters()` | 水平、趋势、季节参数 | 加法/乘法和初始状态 |
| 预测 | `predict()`、教材配套函数 | `n.ahead`, `se.fit` | 点预测与区间、反变换 |
| 预白化/互相关 | `ccf()` 加自定义滤波 | 滞后方向 | 先预白化、明确正负滞后 |
| 状态空间 | 教材相应实现 | 状态与观测方程 | 初始状态、缺失和创新诊断 |

### 14.1 一个常见书写错误

`arima()` 的阶数应写为：

```r
order = c(p, d, q)
```

而不是把首尾均写成 \(q\)。任何代码审查都应核对函数调用与正文模型是否一致。

```r
# 0. 环境 ---------------------------------------------------------------

stopifnot(!anyDuplicated(dat$time))

pacf(y, na.action = na.pass)

# 4. 候选模型 -----------------------------------------------------------
fit1 <- arima(y,
              order = c(p1, d1, q1),
              seasonal = list(order = c(P1, D1, Q1),
                              period = seasonal_frequency),
              method = "ML")

fit2 <- arima(y,
              order = c(p2, d2, q2),
              seasonal = list(order = c(P2, D2, Q2),
                              period = seasonal_frequency),
              method = "ML")

# 5. 诊断 ---------------------------------------------------------------
check_fit <- function(fit, lag = 24L, fitdf = 0L) {
  r <- residuals(fit)
  op <- par(mfrow = c(2, 2))
  on.exit(par(op), add = TRUE)
  plot(r, main = "Residuals")
  acf(r, na.action = na.pass, main = "Residual ACF")
  acf(r^2, na.action = na.pass, main = "Squared residual ACF")
  qqnorm(r); qqline(r)
  Box.test(r, lag = lag, type = "Ljung-Box", fitdf = fitdf)
}

# 6. 预测 ---------------------------------------------------------------
pred <- predict(fit1, n.ahead = H)

# 7. 保存 ---------------------------------------------------------------
saveRDS(fit1, "output/model_primary.rds")
writeLines(capture.output(sessionInfo()), "output/sessionInfo.txt")
```

## 17. 一票否决型问题

以下任一问题均足以使时间序列结论不可靠：

1. 时间频率或时间戳定义错误；
2. 将缺失时点编码为 0；
3. 干预前后聚合或检测制度不同却未说明；
4. 对自相关序列使用普通独立误差回归并解释其 P 值；
5. 随机拆分时间点做预测验证；
6. 使用完整数据选择模型后声称测试期独立；
7. 不报告残差诊断；
8. 把预测区间写成参数置信区间；
9. 只选取最显著滞后而不说明选择过程；
10. 把转换函数或 VAR 的滞后关系直接解释为因果；
11. 自动删除异常点而不追溯机制；
12. 模型未收敛或参数违反平稳/可逆条件仍继续解释；
13. 干预时点与季节峰或同期政策完全重合而无敏感性分析；
14. 计数结局存在变化分母却未使用率、offset 或标准化；
15. 代码、软件版本和最终模型对象无法重建。

## 18. 核心原则

> **模型选择的终点不是最低 AIC，而是一个与任务一致、参数可辨识、残差近似创新、样本外表现可接受且解释边界清楚的动态模型。**

时间序列分析最重要的专业能力，是能够区分哪些变化可由过去结构预测，哪些变化代表外部输入或制度改变，哪些只是随机创新，以及当前证据允许对未来、干预或系统控制作出多强的结论。
