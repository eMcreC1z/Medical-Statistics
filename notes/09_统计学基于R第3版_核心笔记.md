# 《统计学——基于 R（第 3 版）》核心笔记

## 0. 阅读定位与资料边界

本笔记依据贾俊平编著《统计学——基于 R（第 3 版）》整理。教材共 11 章，内容由数据、抽样和 R 基础开始，依次进入数据可视化、描述统计、概率分布、参数估计、假设检验、类别变量分析、方差分析、线性回归、多元回归和时间序列预测。

教材的突出特点，是把统计学知识与 R 操作同步呈现：统计概念不是脱离数据的公式，R 代码也不是脱离估计目标的命令清单。全书可压缩为以下证据链：

> **数据来源与抽样 → 变量结构 → 可视化与统计描述 → 概率模型 → 参数估计 → 假设检验 → 关系建模 → 预测。**

> **资料边界**：上传文件为扫描版。本笔记以可辨认的前言、目录、章节结构、图表和示例页面为主要依据；无法可靠辨认的个别公式、数值与代码不作逐字复原。文中标记为“科研实践扩展”的内容，是基于教材主线形成的严格化解释，不应倒推为教材原文。

## 1. 全书结构不是“检验目录”，而是统计推理的连续过程

| 层级 | 章节主线 | 需要形成的能力 |
|---|---|---|
| 数据层 | 数据类型、数据来源、抽样、R 数据对象与操作 | 判断数据如何产生、变量代表什么、观察单位是否独立 |
| 描述层 | 频数分布、统计图、集中趋势、离散程度和分布形态 | 在建模前识别偏态、异常值、亚组结构和尺度差异 |
| 概率层 | 随机变量与常用概率分布 | 把随机波动写成可计算的概率模型 |
| 推断层 | 点估计、区间估计、假设检验 | 从样本统计量推断总体参数并量化不确定性 |
| 比较层 | 类别变量分析、方差分析 | 在正确的风险集和误差结构下比较组间差异 |
| 建模层 | 一元与多元线性回归 | 估计条件关联、解释系数、诊断模型和限制外推 |
| 预测层 | 时间序列分解、平滑、趋势和季节预测 | 尊重时间顺序，评价样本外预测误差 |

教材的价值不在于某个函数如何输入，而在于把以下三件事对应起来：

1. 科学问题对应什么总体参数；
2. 参数估计依赖什么数据结构和概率模型；
3. R 输出中的统计量、置信区间和 P 值应如何解释。

## 2. 数据与 R：统计分析从数据产生机制开始

### 2.1 变量的统计角色比存储类型更重要

教材区分类别变量和数值变量，并进一步讨论横截面数据、时间序列数据及其组合。实际分析中，应同时记录变量的四种属性：

- **测量尺度**：名义、有序、区间或比率；
- **研究角色**：结局、暴露、处理、混杂因素、效应修饰因素或标识变量；
- **时间属性**：基线、随访、时变或事件发生时间；
- **数据结构**：独立、配对、重复测量、分层或聚类。

相同的数值编码可能有完全不同的统计含义。例如，性别编码为 0/1 仍是类别变量；疼痛等级编码为 1～5 仍不自动具有等距性质；患者编号即使是整数，也不能作为连续自变量进入回归。

### 2.2 抽样决定推广范围

教材介绍简单随机抽样、分层抽样、整群抽样、系统抽样等概率抽样思路，也涉及便利抽样、判断抽样等非概率方式。真正需要掌握的是：

\[
\text{样本代表性} \neq \text{样本量大}
\]

样本量只能降低随机误差，不能自动修复覆盖不足、无应答、选择机制或测量偏倚。任何推断都应明确：

- 目标总体是什么；
- 抽样框覆盖了谁；
- 谁进入了最终分析集；
- 样本与总体之间依靠何种机制建立联系。

### 2.3 R 的基本对象应服务于数据语义

教材从向量、矩阵、数据框、因子和对象属性进入 R。统计分析中最容易产生隐蔽错误的不是语法，而是对象语义：

- 因子水平与参照组错误；
- 字符和数值在导入时被错误转换；
- 缺失值被编码为 0、999 或空字符串；
- 合并数据时主键不唯一；
- 宽表和长表转换后观察单位发生改变；
- 排序、筛选或删除后行号被误当作受试者编号。

因此，读入数据后至少应核查 `dim()`、`names()`、`str()`、`summary()`、唯一标识和各类别频数，而不是立即进入模型。

## 3. 数据可视化：图形是模型设定前的诊断工具

教材第二章分别讨论类别数据和数值数据的频数分布及可视化，并展示条形图、堆积图、马赛克图、直方图、茎叶图、箱线图、密度图和变量关系图等。

### 3.1 单变量图形回答分布问题

- 条形图用于类别频数或比例；
- 直方图和密度图用于连续变量分布形态；
- 箱线图用于中位数、四分位数和异常观测的初步识别；
- 茎叶图在小样本中兼顾分布形态与原始数值；
- 时间序列图用于趋势、季节性、突变和异常时点。

### 3.2 双变量和多变量图形回答结构问题

散点图应先于相关和回归。它能够发现：

- 非线性；
- 异方差；
- 亚组或混合分布；
- 高杠杆点；
- 范围受限；
- 时间顺序或批次效应。

列联表的可视化应明确分母。行百分比、列百分比和总体百分比回答不同问题，图中不注明分母会直接改变结论。

### 3.3 【科研实践扩展】图形设计原则

优先使用位置、长度和共同基线表达差异；三维饼图、透视柱图和面积夸张会增加视觉误差。研究报告中的图形应同时表达：

- 原始数据或分布；
- 点估计；
- 不确定性；
- 样本量或风险集；
- 必要的分层和时间信息。

图形不是结果的装饰，而是分析证据的一部分。

## 4. 描述统计：位置、尺度和形状必须联合报告

教材第三章围绕集中趋势、离散程度、分布形态和综合描述展开。

### 4.1 集中趋势

| 数据特征 | 推荐指标 | 解释重点 |
|---|---|---|
| 近似对称、无严重异常值 | 均数 | 所有观测的算术中心 |
| 右偏、左偏或有开口组段 | 中位数 | 50% 分位位置，对极端值较稳健 |
| 乘法变化或对数正态 | 几何均数 | 对数尺度均数回到原尺度后的中心 |
| 类别频数 | 众数 | 最常见类别，不代表数量平均 |

### 4.2 离散程度

- 极差只使用两个端点，稳定性较差；
- 四分位数间距描述中间 50% 数据；
- 方差和标准差描述相对均数的平方偏差；
- 变异系数用于尺度不同资料的相对变异比较，但均数接近 0 时失去稳定解释。

必须区分：

\[
SD = \text{个体观测值的离散程度}, \qquad
SE = \text{统计量抽样分布的离散程度}
\]

### 4.3 分布形态

偏度和峰度是分布形态的数值摘要，但不能替代图形。均数、中位数、标准差、四分位数、偏度和峰度应结合直方图、密度图、箱线图与 Q-Q 图共同判断。

### 4.4 标准化的含义

标准化常写为：

\[
z_i = \frac{x_i-\bar{x}}{s}
\]

它消除了位置和尺度，使不同量纲变量可比较。但标准化不会消除偏态、异常值、测量误差或混杂，也不会使变量自动服从正态分布。

## 5. 概率分布：理解 R 中 `d/p/q/r` 四类函数

教材第四章把离散随机变量和连续随机变量与二项、泊松、正态、卡方、t、F 等常用分布联系起来。

R 对多数分布采用统一命名：

| 前缀 | 含义 | 例：正态分布 |
|---|---|---|
| `d` | 概率质量或概率密度 | `dnorm()` |
| `p` | 累积分布概率 | `pnorm()` |
| `q` | 分位数 | `qnorm()` |
| `r` | 随机数生成 | `rnorm()` |

掌握分布不应停留在“查表”，而应理解四个对象：

1. 随机变量的支持集；
2. 参数控制什么形状或尺度；
3. 统计量在原假设下服从何种分布；
4. 分布假定错误会怎样影响估计、标准误和检验。

二项分布对应固定试验次数下的成功次数；泊松分布常用于给定暴露量或观察时间内的事件计数；t、卡方和 F 分布则大量出现在均数、方差和线性模型的推断中。

## 6. 参数估计：先定义参数，再计算区间

教材第五章讨论点估计和区间估计，包括单总体、两总体均数和比例等经典参数。

### 6.1 点估计不是结论

一个估计值必须附带：

- 估计对象；
- 单位；
- 标准误；
- 置信区间；
- 样本量和分析集；
- 估计成立的设计与模型条件。

### 6.2 置信区间的四个决定因素

置信区间宽度通常由置信度、样本量、数据变异和设计效率共同决定。增加样本量能够提高精度，但不能降低系统偏倚。

### 6.3 置信区间与预测区间

回归均值的置信区间描述条件均值的不确定性；新个体的预测区间还包含个体残差变异，因此通常更宽。两者不能互换。

## 7. 假设检验：P 值只是证据度量的一部分

教材第六章系统处理假设检验原理、总体均数、比例、方差及非参数检验。

### 7.1 检验的逻辑

\[
H_0 \rightarrow \text{原假设下统计量分布}
\rightarrow \text{观测统计量}
\rightarrow P\text{ 值}
\rightarrow \text{结合 }\alpha\text{ 作决策}
\]

P 值是：在原假设和统计模型成立时，获得当前统计量或更极端结果的概率。它不是原假设为真的概率，也不是研究结果“由随机误差造成”的概率。

### 7.2 单侧与双侧

单侧备择假设必须在观察数据之前由科学问题确定。看到结果方向后再改单侧检验，会人为降低 P 值并破坏预先规定的错误率。

### 7.3 参数检验与非参数检验

非参数方法通常减少对具体分布形式的依赖，但并非“无假定”。秩检验仍依赖独立性、可交换性及相应位置或分布比较的条件；显著结果不能在任意条件下直接解释为中位数差异。

### 7.4 最低报告要求

> **效应估计 + 95% 置信区间 + 精确 P 值 + 样本量 + 参照组 + 单位。**

“有统计学意义”不能替代效应大小和实际意义。

## 8. 类别变量分析：列联表中的分母决定解释

教材第七章围绕拟合优度、独立性检验和类别变量关联展开。

分析列联表前应先回答：

- 行和列分别代表什么；
- 比例以谁为分母；
- 数据是否独立；
- 是否存在配对、分层或重复测量；
- 期望频数是否支持渐近卡方近似。

卡方检验回答总体分布或独立性问题，本身不提供效应方向与临床大小。2×2 表至少应根据设计补充风险差、风险比、比值比或相应置信区间。小样本或稀疏表需要考虑精确方法，但精确检验也不能修复选择偏倚和错误分类。

## 9. 方差分析：本质是线性模型的平方和分解

教材第八章包括单因素、双因素方差分析、假定检验和非参数替代。

基本分解为：

\[
SS_{Total}=SS_{Model}+SS_{Error}
\]

F 检验比较模型解释变异与随机误差变异。需要特别掌握：

- 总体检验显著不等于任意两组均有差异；
- 多重比较必须控制整体错误率；
- 双因素设计应先解释交互作用，再解释主效应；
- 方差齐性、残差正态性和独立性针对误差结构，而不是机械要求每组原始数据完全正态；
- 重复测量、聚类或配对数据不能按普通独立样本 ANOVA 分析。

【科研实践扩展】ANOVA 与回归属于统一的线性模型框架。把处理因素编码为设计矩阵后，组间比较、协方差分析、趋势检验和交互作用都可以在同一模型中表达。

## 10. 线性回归：系数解释必须以条件结构为前提

### 10.1 一元线性回归

\[
Y_i=\beta_0+\beta_1X_i+\varepsilon_i
\]

其中，\(\beta_1\) 表示在模型范围内 X 每增加一个单位，Y 的条件均值平均改变多少。回归系数、相关系数和决定系数回答不同问题：

- 回归系数有单位，表达效应尺度；
- 相关系数无单位，表达线性关系方向和强度；
- \(R^2\) 描述样本中被模型解释的变异比例，不等于因果解释比例，也不保证样本外预测能力。

### 10.2 多元线性回归

多元模型中的偏回归系数表示：在其他变量保持不变的条件下，某一自变量变化一个单位时结局条件均值的变化。该“保持不变”是模型条件解释，不自动具有干预或因果含义。

必须检查：

- 函数形式；
- 残差同方差性；
- 独立性；
- 残差分布；
- 多重共线性；
- 高杠杆点和强影响点；
- 模型设定与外推范围。

### 10.3 变量选择的边界

逐步选择能生成较简洁的模型，但结果依赖进入和剔除阈值，可能造成系数偏倚、标准误偏小和选择不稳定。病因研究应以专业知识、时间顺序和因果结构确定调整集；预测研究应依靠重抽样、惩罚和外部验证评价泛化能力。

## 11. 时间序列预测：随机划分会破坏时间信息

教材第十一章涉及时间序列构成、预测方法、平滑、趋势和季节性。

时间序列通常可分解为：

\[
Y_t = T_t + S_t + C_t + I_t
\]

或在乘法结构下写为 \(Y_t=T_t\times S_t\times C_t\times I_t\)。其中分别表示趋势、季节、周期和不规则成分。

预测分析应关注：

- 时间索引是否连续；
- 是否存在趋势、季节和结构突变；
- 残差是否仍有自相关；
- 预测区间是否随步长扩大；
- 评价是否基于未来时段而不是随机抽取的测试集。

常用误差指标如 MAE、RMSE、MAPE 各有不同尺度含义。模型选择不能只看样本内拟合，必须采用保留末端时段或滚动起点的样本外评价。

## 12. R 实现路径速查

| 任务 | 典型 R 路径 | 必须同时检查 |
|---|---|---|
| 数据结构 | `str()`、`summary()`、`table()` | 类型、单位、缺失、唯一标识 |
| 抽样 | `sample()` | 抽样框、放回方式、分层或聚类结构 |
| 描述统计 | `mean()`、`median()`、`quantile()`、`sd()` | 分布形态与异常值 |
| 图形 | `barplot()`、`hist()`、`boxplot()`、`plot()`、`density()` | 分母、坐标尺度、原始数据 |
| 概率分布 | `d*`、`p*`、`q*`、`r*` | 参数化方式和支持集 |
| 均数比较 | `t.test()` | 独立/配对、方差、效应量和区间 |
| 比例与列联表 | `prop.test()`、`chisq.test()`、`fisher.test()` | 期望频数、分层、配对结构 |
| 非参数比较 | `wilcox.test()`、`kruskal.test()` | 目标参数及分布形状 |
| 方差分析 | `aov()`、`lm()` | 交互、对比、残差和多重比较 |
| 回归 | `lm()`、`confint()`、`predict()` | 函数形式、影响点、共线性、外推 |
| 时间序列 | `ts()`、平滑与预测函数 | 时间顺序、季节频率、样本外误差 |

函数运行成功只说明语法可执行，不说明估计目标、数据结构或统计假定正确。

## 13. 精通层面的审读清单

完成一项分析前，应能回答以下问题：

1. 观察单位、目标总体和分析总体分别是什么？
2. 数据通过何种抽样、实验或观察机制产生？
3. 主要估计目标是均数差、比例差、比值、回归系数还是预测误差？
4. 变量的测量尺度、时间顺序和依赖结构是什么？
5. 图形是否提示非线性、异方差、亚组、异常值或时间结构？
6. 所用概率分布是数据模型、误差模型还是检验统计量分布？
7. 置信区间对应总体参数、均值响应还是新个体预测？
8. P 值之外，效应量和实际意义是什么？
9. 多重比较、变量选择和反复试模是否改变错误率？
10. 模型诊断、敏感性分析和样本外验证是否支持最终解释？

## 14. 核心心得

《统计学——基于 R》最值得吸收的，不是某个检验的计算流程，而是把数据、概率、推断和计算连成一体。R 使统计计算快速，但也使未经思考的分析更容易批量发生。真正的统计能力表现为：

> **先识别数据产生机制，后定义估计目标；先观察分布和结构，后选择模型；先核查假定和稳定性，后解释 P 值；先验证样本外表现，后谈预测。**
