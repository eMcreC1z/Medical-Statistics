# 《数据挖掘与 R 语言》核心笔记

## 0. 阅读定位与资料边界

本笔记依据 Luís Torgo 的 *Data Mining with R: Learning with Case Studies* 中文译本整理。可辨认目录显示，全书采用“方法最少化、案例完整化”的结构：

1. 第一章介绍 R、对象、向量、因子、矩阵、数据框、公式、函数和数据库连接；
2. 第二章给出预测问题的完整工作流，包括问题定义、数据获取、探索、建模、评估、交叉验证和性能估计；
3. 第三章研究股票市场收益预测；
4. 第四章研究欺诈交易检测；
5. 第五章研究微阵列样本分类。

全书的核心价值在于：不是把分类、回归和异常检测拆成互不相干的算法，而是把每个案例从目标定义、数据准备、模型选择、评价到结果解释完整走一遍。

## 1. 数据挖掘不是“跑多个模型取最高准确率”

预测项目至少包含四个互相约束的对象：

| 对象 | 需要定义的问题 |
|---|---|
| 预测单位 | 患者、就诊、样本、交易、时间窗还是中心 |
| 目标变量 | 在什么时间窗内、由什么标准定义 |
| 信息集 | 预测时点真正可获得哪些变量 |
| 决策与损失 | 谁使用预测、做什么行动、不同错误代价如何 |

若这些对象未定义，AUC、RMSE 或准确率再高也没有稳定解释。

### 1.1 描述、解释与预测不同

- 描述：数据中发生了什么；
- 解释：哪些变量与结果关联；
- 因果：改变某变量是否改变结果；
- 预测：新个体结果能否被准确预测；
- 决策：预测是否改善行动和结局。

同一算法可用于不同目标，但验证和结论语言必须改变。

## 2. R 数据对象决定分析语义

原书第一章从向量、因子、矩阵、数据框、列表、公式和函数开始。精通层面需要关注的不只是语法，而是类型如何改变统计模型。

### 2.1 因子与数值编码

- `factor` 水平决定设计矩阵和参照组；
- 将类别 1、2、3 当连续数值会隐含等距和线性趋势；
- 训练集与测试集因子水平不一致会导致预测失败或错误编码；
- 缺失类别、未知类别和真正的 `NA` 应分开。

### 2.2 公式接口

R 公式

```r
y ~ x1 + x2 + x1:x2
```

编码主效应和交互。`x1 * x2` 通常展开为 `x1 + x2 + x1:x2`。复杂模型中应检查实际设计矩阵：

```r
mm <- model.matrix(fit)
colnames(mm)
qr(mm)$rank
```

以发现虚拟变量、共线性、空单元和不可估参数。

### 2.3 数据库到分析集

原书涉及 MySQL 连接。数据库查询本身属于分析证据链：

- join 键是否唯一；
- 一对多连接是否复制记录；
- 时间条件是否按可用时间而非最终时间；
- SQL 聚合是否改变分母；
- 数据库快照能否重建；
- 排除规则是否版本化。

## 3. 预测问题的规范定义

建议用以下模板定义任务：

> 在目标人群 \(P\) 中，使用预测时点 \(t_0\) 前可获得的信息 \(X(t_0)\)，预测时间范围 \((t_0,t_0+h]\) 内结局 \(Y_h\)，用于决策 \(A\)，并以损失函数 \(L(Y_h,A)\) 评价。

### 3.1 标签定义

标签必须明确：

- 临床金标准或代理指标；
- 时间窗口；
- 多次事件如何处理；
- 竞争事件；
- 标签延迟；
- 误分类；
- 由未来信息生成的标签是否泄漏到特征。

### 3.2 基线率与应用患病率

类别比例影响：

- 预测值；
- 准确率；
- 阈值；
- 决策效用；
- 重采样策略；
- 外部部署性能。

病例—对照或人为平衡训练集上的概率必须重新校准到目标人群基线率。

## 4. 数据获取与数据审计

### 4.1 数据来源不是背景信息

应记录：

- 抽样框架；
- 纳入排除；
- 数据采集时间；
- 中心、设备和批次；
- 测量协议；
- 缺失机制；
- 标签获取流程；
- 数据修订和冻结日期。

### 4.2 重复和依赖

同一患者可有多个样本或就诊，同一中心可有多个患者，同一基因芯片可含多个探针。若随机按行划分，训练和测试会共享信息。

划分单位应与独立推广单位一致：

- 患者级；
- 家庭级；
- 医院级；
- 时间级；
- 批次级；
- 地区级。

### 4.3 数据泄漏审计

每个候选变量应回答：

1. 在预测时点是否存在；
2. 是否由结局或后续处理衍生；
3. 是否包含医生已知结局后的行为；
4. 是否通过全数据标准化、插补或筛选泄漏；
5. 是否是中心、批次或编码规则的代理。

## 5. 探索性数据分析服务于错误发现和模型设定

### 5.1 目标分布

- 连续结局：偏态、极端值、异方差、测量上下限；
- 二分类：基线率和时间变化；
- 计数：过度离散、零膨胀、暴露量；
- 生存：随访分布、删失、竞争风险；
- 时间序列：趋势、季节、漂移和前瞻。

### 5.2 特征结构

- 缺失率和缺失模式；
- 低方差或近零方差变量；
- 高相关和重复变量；
- 非线性；
- 极端值和批次效应；
- 类别稀疏水平；
- 训练与测试分布差异。

### 5.3 EDA 不能污染验证

探索可以在开发数据中充分进行，但测试集应被冻结。基于测试集观察到的模式调整特征、阈值或模型，相当于把测试集转为训练集。

## 6. 预处理必须嵌入重抽样

所有由数据估计的步骤组成一个 preprocessing recipe：

- 缺失填补；
- 标准化；
- 变量变换；
- 类别合并；
- 特征筛选；
- PCA；
- 过采样/欠采样；
- SMOTE；
- 批次校正；
- 阈值选择。

在第 \(k\) 个验证折中，应只用训练折拟合上述步骤，再应用于验证折。形式上：

\[
\widehat{\mathcal P}^{(-k)}
=\operatorname{fitPreprocess}(D_{train}^{(-k)}),
\]

\[
\tilde D_{train}^{(-k)}
=\widehat{\mathcal P}^{(-k)}(D_{train}^{(-k)}),
\qquad
\tilde D_{valid}^{(k)}
=\widehat{\mathcal P}^{(-k)}(D_{valid}^{(k)}).
\]

先在全数据上筛选基因或标准化，再做交叉验证，是高维研究最常见的乐观偏倚来源之一。

## 7. 候选模型：从透明基线到复杂学习器

### 7.1 基线模型

- 连续结局：均值、线性回归、简单树；
- 二分类：基线率、logistic 回归；
- 时间序列：最近值、季节最近值、线性趋势；
- 稀有事件：固定规则或简单风险评分。

复杂模型必须证明相对于基线的增量价值。

### 7.2 常见模型族

| 模型 | 优势 | 风险 |
|---|---|---|
| 线性/logistic | 透明、易校准、可正则化 | 非线性和交互需指定 |
| kNN | 局部、直观 | 尺度、高维和计算敏感 |
| 树 | 自动交互、规则清晰 | 不稳定、分段常数 |
| 随机森林 | 非线性、交互、稳健预测 | 概率校准和解释困难 |
| Boosting | 强预测、灵活损失 | 调参、过拟合和漂移 |
| SVM | 高维间隔分类 | 概率输出和尺度敏感 |
| 神经网络 | 表征能力强 | 数据需求、可复现和解释 |
| 集成 | 降低单模型风险 | 复杂度、治理和部署成本 |

模型复杂度应与有效样本量、事件数、中心数和独立信息量匹配。

## 8. 重抽样和性能估计

原书第二章重视交叉验证和性能估计。精通层面需区分三层数据用途：

1. **训练**：拟合参数；
2. **调优/选择**：选择特征、超参数和模型；
3. **最终评价**：估计冻结模型的泛化性能。

### 8.1 嵌套交叉验证

外层估计整个建模流程的性能，内层选择超参数：

```text
for outer split:
    freeze outer test
    within outer train:
        tune preprocessing + model by inner resampling
    refit selected pipeline on outer train
    evaluate once on outer test
aggregate outer predictions
```

普通交叉验证后选择最佳模型，再用同一交叉验证分数报告性能，会产生选择偏倚。

### 8.2 不同数据结构的划分

- i.i.d. 个体：分层重复交叉验证；
- 同一患者多记录：grouped CV；
- 多中心：leave-one-center-out 或 internal-external CV；
- 时间数据：rolling-origin 或未来时段留出；
- 家庭/社区聚类：按聚类单元划分；
- 小样本高维：嵌套 CV + Bootstrap 稳定性。

### 8.3 置信区间

性能指标的不确定性应尊重依赖结构。对患者级预测可按患者 Bootstrap；多中心研究可同时报告中心间分布和层级不确定性。把所有预测行当独立会低估标准误。

## 9. 性能指标必须与任务和基线率匹配

### 9.1 分类

| 指标 | 主要含义 | 限制 |
|---|---|---|
| Accuracy | 总体正确率 | 类别不平衡时误导 |
| Sensitivity | 病例识别率 | 不反映假阳性负担 |
| Specificity | 非病例识别率 | 不反映漏诊代价 |
| PPV/NPV | 预测后的实际概率 | 依赖患病率 |
| AUROC | 随机病例排序高于非病例概率 | 对临床阈值和稀有事件不敏感 |
| AUPRC | 阳性预测质量与召回权衡 | 强依赖基线率 |
| Log loss/Brier | 概率预测质量 | 需结合校准解释 |
| Net benefit | 阈值下临床效用 | 依赖决策场景 |

### 9.2 连续预测

- MAE：绝对误差的典型大小；
- RMSE：更惩罚大误差；
- \(R^2\)：相对于基准的方差解释；
- 校准截距和斜率；
- 预测区间覆盖；
- 临床容许误差范围内比例。

### 9.3 阈值不是模型固有属性

最佳阈值取决于：

- 患病率；
- 假阳性和假阴性成本；
- 后续干预能力；
- 资源限制；
- 患者偏好。

在测试集上选择阈值再报告同一测试集性能会过度乐观。

## 10. 案例一：股票市场收益预测

原书第三章用股票市场收益展示时间序列预测和交易决策。该案例的普遍价值在于：预测正确不等于可获益。

### 10.1 时间顺序

- 特征只能使用交易时点前可获得数据；
- 训练和测试必须按时间分割；
- 价格复权、停牌和成分股变化不能使用未来修订；
- 滚动窗口应模拟重新训练过程。

### 10.2 目标选择

预测价格、收益、收益方向、波动率和超额收益是不同任务。原始价格通常非平稳，差分或收益更接近可建模对象，但模型输出仍需转为行动规则。

### 10.3 经济效用

评价需加入：

- 交易成本；
- 买卖价差；
- 延迟；
- 滑点；
- 持仓限制；
- 风险调整收益；
- 最大回撤；
- 多重策略搜索偏倚。

医学类比：模型 AUC 提升不等于患者结局改善；必须通过决策规则和下游成本收益评价。

## 11. 案例二：欺诈交易检测

原书第四章处理欺诈交易，典型特征是类别极度不平衡、误分类代价不对称、欺诈策略随时间变化。

### 11.1 稀有事件

若欺诈率为 0.1%，全部预测“正常”即可获得 99.9% accuracy，但没有任何检测价值。因此应优先看：

- precision/PPV；
- recall/sensitivity；
- PR 曲线；
- 每千笔误报数；
- 捕获金额；
- 调查工作量；
- 检测延迟。

### 11.2 代价敏感学习

设假阴性成本为 \(C_{FN}\)，假阳性成本为 \(C_{FP}\)。若预测概率校准，可按期望损失选择阈值：

\[
\text{采取行动当}
\quad
p(Y=1\mid X)
>
\frac{C_{FP}}
{C_{FP}+C_{FN}}.
\]

实际成本还可能随交易金额、患者风险和资源变化，阈值应个体化或受容量约束。

### 11.3 重采样

欠采样、过采样和 SMOTE 只能用于训练折。它们改变训练分布，概率输出需重新校准到真实基线率。

### 11.4 漂移

欺诈者会适应检测规则，形成概念漂移。医学 AI 中编码规则、诊疗路径、设备和人群同样会漂移，因此部署后监测不可省略。

## 12. 案例三：微阵列样本分类

原书第五章讨论微阵列分类，是典型 \(p\gg n\) 问题：变量数远大于样本数。

### 12.1 高维数据的特殊风险

- 任意随机标签也可能找到表面高准确率特征；
- 变量相关簇导致选择不稳定；
- 批次效应可强于生物信号；
- 预处理和归一化决定下游结构；
- 同一患者多个样本会泄漏；
- 小测试集指标极不稳定。

### 12.2 特征筛选必须嵌套

错误流程：

```text
全数据差异分析选基因
→ 对选中基因做交叉验证
```

正确流程：

```text
每个训练折内：
  归一化/批次处理
  → 选基因
  → 调参
  → 拟合
  → 应用于验证折
```

外层测试数据不得参与任何特征筛选。

### 12.3 选择稳定性

除了预测性能，应报告：

- 每个特征入选频率；
- 不同重抽样下特征集合 Jaccard 相似度；
- 通路或模块层面稳定性；
- 不同平台、批次和中心中的可重复性；
- 简化签名后的性能损失。

### 12.4 外部验证

真正的生物标志物签名需要独立队列、独立实验平台或时间后移验证。内部交叉验证只能估计当前开发流程在相似来源数据中的性能。

## 13. 解释模型与解释预测

### 13.1 回归系数

条件系数描述在模型中其他变量固定时的条件关联。它不等于：

- 因果效应；
- 变量的总贡献；
- 删除变量后的性能损失；
- 临床可干预性。

### 13.2 变量重要性

树、随机森林、置换重要性、SHAP 和标准化系数衡量不同对象。相关变量中，重要性可被分摊、替代或偏置。

### 13.3 局部解释

单个患者的解释需要区分：

- 模型为何输出该概率；
- 哪些输入对输出敏感；
- 改变变量是否会改变真实结局；
- 解释在数据分布外是否稳定。

预测解释不是反事实因果解释。

---

## 14. 模型校准与再校准

> 本节为现代实践扩展。

二分类概率预测可评价：

- 校准图；
- calibration-in-the-large；
- 校准斜率；
- Brier 分数；
- 分层和亚组校准。

外部数据中可先进行截距更新：

\[
\operatorname{logit}(p_{new})
=\alpha+\operatorname{logit}(p_{old}),
\]

再考虑斜率更新或重新拟合。再校准策略必须在独立更新集上估计，在独立评估集上验证。

## 15. 模型部署与持续监测

> 本节为工程实践扩展。

### 15.1 冻结对象

应版本化：

- 数据抽取；
- 变量字典；
- 预处理；
- 模型对象；
- 阈值；
- 软件依赖；
- 训练数据时间；
- 性能基线。

### 15.2 漂移类型

| 漂移 | 含义 | 监测示例 |
|---|---|---|
| 协变量漂移 | \(P(X)\) 变化 | PSI、距离、分位数 |
| 标签漂移 | \(P(Y)\) 变化 | 事件率、延迟校正率 |
| 概念漂移 | \(P(Y\mid X)\) 变化 | 校准斜率、残差 |
| 流程漂移 | 数据生成/编码改变 | 数据字典、缺失、单位 |
| 决策漂移 | 使用模型后的行动改变 | 干预率、覆盖率 |

### 15.3 回滚和安全

必须预设：

- 输入缺失时的降级策略；
- 模型不可用时的基线规则；
- 超出训练分布时的拒绝或警示；
- 性能恶化阈值；
- 人工复核；
- 更新审批和回滚。

## 17. 医学预测建模最低核查表

### 问题

- [ ] 目标人群、预测时点、预测范围和用途明确；
- [ ] 标签来源、窗口和误分类已说明；
- [ ] 错误成本和行动阈值有临床依据。

### 数据

- [ ] 患者、中心、时间和批次依赖已识别；
- [ ] 所有变量在预测时点可用；
- [ ] 缺失、单位、异常和重复已审计；
- [ ] 训练数据与应用人群差异已说明。

### 建模

- [ ] 有透明基线；
- [ ] 预处理和筛选嵌入重抽样；
- [ ] 超参数在内层调优；
- [ ] 复杂度与有效样本信息相称；
- [ ] 预测概率被校准。

### 评价

- [ ] 有患者/中心/时间隔离；
- [ ] 最终测试集仅使用一次；
- [ ] 报告判别、校准、临床效用及不确定性；
- [ ] 评价亚组和中心异质性；
- [ ] 有外部或前瞻验证。

### 部署

- [ ] 数据和模型版本可重建；
- [ ] 漂移和标签延迟被监测；
- [ ] 有安全降级和回滚；
- [ ] 更新不会污染后续评价。

## 18. 精通层训练任务

1. 重现一个完整分类案例，并将所有预处理嵌入嵌套交叉验证。
2. 构造一个泄漏变量，量化随机划分与患者级划分的性能差异。
3. 在稀有事件数据中比较 AUROC、AUPRC、PPV、Brier 和净获益。
4. 对欠采样和 SMOTE 后的概率进行再校准，比较部署人群性能。
5. 模拟 \(p\gg n\) 微阵列数据，比较全数据筛选与折内筛选的乐观偏倚。
6. 评价特征选择稳定性和通路层面稳定性。
7. 用时间滚动验证重做一个金融或医疗动态预测案例。
8. 设计一个多中心 internal-external CV，并绘制中心特异性能。
9. 为模型建立数据漂移和校准监控报告。
10. 把整个流程封装为 R package 或可复现 pipeline，并通过单元测试验证时间边界和数据类型。

## 19. 精通层结论

1. 数据挖掘的真正单位是完整分析流程，而不是单个算法。
2. 预测问题必须同时定义人群、时间、目标、信息集、行动和损失。
3. 数据预处理、特征筛选和阈值选择都是训练过程，必须嵌入重抽样。
4. 股票、欺诈和微阵列三个案例分别揭示时间前瞻、类别不平衡和高维选择偏倚，是医学数据科学同样面临的核心风险。
5. 交叉验证只有在划分单位与未来推广单位一致时才有意义。
6. 高准确率不能替代校准、临床效用、外部验证和部署监测。
7. 模型解释不能自动转化为病因解释或干预建议。
8. 医学数据科学专家必须能够审计从数据库查询到临床行动的全链路，而不仅是比较模型排行榜。
