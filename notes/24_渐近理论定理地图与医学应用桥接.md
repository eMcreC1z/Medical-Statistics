# 渐近理论定理地图与医学应用桥接

## 0. 文件定位

本文件以 *Asymptotic Statistics* 的理论主线为骨架，并连接《统计推断》与医学统计实践。目标不是替代严格证明，而是为每个核心结果回答六个问题：

1. 它解决什么统计困难；
2. 条件是什么；
3. 结论是什么；
4. 在医学方法中对应什么；
5. 何时会失效；
6. 如何通过模拟核查。

本文包含整合性医学应用解释。定理的严格表述和证明应以原书为准。

## 2. 大数定律（LLN）

### 2.1 原型

若 \(X_1,X_2,\ldots\) i.i.d. 且 \(E|X|<\infty\)，则

\[
\bar X_n=\frac1n\sum_{i=1}^nX_i\to EX
\]

以依概率或更强方式收敛，具体取决于定理版本。

### 2.2 统计作用

- 样本矩收敛到总体矩；
- log-likelihood 平均值收敛到期望准则；
- estimating equation 收敛到总体方程；
- 经验风险收敛到期望风险。

### 2.3 医学桥接

- 患病率、均值和率的稳定估计；
- GLM score 的总体极限；
- 随访完整且独立时的经验生存量；
- 多中心平均效应估计。

### 2.4 失败风险

- 聚类或时间相关却按 i.i.d.；
- 重尾导致期望不存在；
- 选择机制使经验分布不收敛到目标总体；
- 三角数组或非平稳数据；
- 实际增加的是重复记录而非独立单位。

### 2.5 模拟核查

比较按行增加记录与按患者增加样本时，样本均值方差下降速度；在不同 ICC 下检验“名义 \(n\)”和有效样本量差异。

## 3. 中心极限定理（CLT）

### 3.1 原型

若 i.i.d. 且 \(0<\sigma^2<\infty\)，则

\[
\sqrt n(\bar X_n-\mu)
\rightsquigarrow N(0,\sigma^2).
\]

### 3.2 统计作用

把经验平均的随机波动近似为正态，是 Wald 区间、score、M/Z 估计和影响函数推断的基础。

### 3.3 医学桥接

- 样本均值和风险的区间；
- 影响函数平均的渐近正态；
- cluster-level CLT；
- 多中心 meta-analytic 汇总；
- U 统计量一阶投影后的 CLT。

### 3.4 失败风险

- 无限方差或极重尾；
- 极端不平衡权重；
- 稀有事件使有效信息少；
- 强依赖；
- 权重 positivity 近零；
- 最大值、变点、边界等非平均型统计量。

### 3.5 核查

不要只做正态性检验。模拟当前样本量下标准化统计量、置信区间覆盖和尾部错误率。

---

## 4. 连续映射定理与 Slutsky 引理

### 4.1 原型

若 \(X_n\rightsquigarrow X\) 且 \(Y_n\to_p c\)，则可将一致估计的 nuisance 量代入极限表达式。

### 4.2 统计作用

- 用估计标准误替代真实标准误；
- 将系数转为 OR/HR；
- 组合多个一致估计量；
- 构造学生化统计量。

### 4.3 医学桥接

例如

\[
\frac{\hat\beta-\beta_0}{\widehat{SE}(\hat\beta)}
\rightsquigarrow N(0,1)
\]

需要 \(\widehat{SE}\) 一致。软件输出一个正数不等于一致性已成立。

### 4.4 失败风险

- 分母接近 0；
- 标准误模型错误；
- 非连续变换，如阈值和变量选择；
- 参数位于边界；
- nuisance 估计不一致。

## 5. Delta 方法

### 5.1 原型

若

\[
\sqrt n(T_n-\theta)ightsquigarrow N(0,\Sigma),
\]

且 \(g\) 可微，则

\[
\sqrt n\{g(T_n)-g(\theta)\}
\rightsquigarrow
N\{0,Dg(\theta)\Sigma Dg(\theta)^T\}.
\]

### 5.2 医学应用

- log OR 到 OR；
- log rate ratio 到 rate ratio；
- 风险到 NNT；
- 两风险到 RR/RD；
- sensitivity/specificity 到 likelihood ratio；
- 回归参数到边际标准化效应。

### 5.3 失败风险

- 导数为零；
- 变换在边界不可微；
- 分母风险接近 0；
- NNT 在 RD 近 0 时不稳定；
- 选择最大、最小或截断。

### 5.4 推荐报告

在非线性尺度上优先直接构造 profile、Bootstrap 或模拟区间，并检查对称 Wald 区间是否越界或高度失真。

## 6. 一致性定理：M 估计

### 6.1 结构

\[
\hat\theta_n
=\arg\max_{\theta\in\Theta}M_n(\theta),
\qquad
M(\theta)=PM_\theta.
\]

典型条件：

1. \(\sup_\theta|M_n(\theta)-M(\theta)|\to_p0\)；
2. \(M\) 在 \(\theta_0\) 唯一最大；
3. \(\hat\theta_n\) 近似最大化。

结论：\(\hat\theta_n\to_p\theta_0\)。

### 6.2 医学桥接

- MLE；
- robust regression；
- quantile regression；
- penalized likelihood 的固定惩罚极限；
- empirical risk minimization。

### 6.3 关键理解

一致性依赖**模型内可识别性**。如果两个参数产生相同观测分布，数据量再大也不能区分。

### 6.4 失败风险

- 模型不可识别；
- 参数空间不紧且极值逃逸；
- 仅点态收敛；
- 数据驱动复杂度随 \(n\) 过快增长；
- 分布漂移；
- 目标函数多峰或平坦。

## 7. Argmax 定理

### 7.1 作用

将随机准则函数的收敛传递到最大点位置。局部版本用于得到非标准收敛率和极限分布。

### 7.2 医学应用

- MLE；
- change-point；
- 最佳截点；
- 最大 Youden index；
- spline knot；
- tree split；
- profile likelihood。

### 7.3 失败风险

阈值或最大化位置往往是非光滑参数，普通 \(\sqrt n\) 正态近似和普通 Bootstrap 可能失效。使用“数据驱动最佳 cut-off”后直接报告其 Wald 区间通常不可靠。

---

## 8. Z 估计渐近正态性

### 8.1 原型

若

\[
\mathbb P_n\psi_{\hat\theta}=0,
\qquad
P\psi_{\theta_0}=0,
\]

且可线性化，则

\[
\sqrt n(\hat\theta-\theta_0)
=-A^{-1}\frac1{\sqrt n}
\sum_{i=1}^n\psi_{\theta_0}(O_i)+o_p(1),
\]

\[
A=P\dot\psi_{\theta_0}.
\]

极限协方差

\[
A^{-1}BA^{-T},
\qquad
B=P\psi\psi^T.
\]

### 8.2 医学应用

- GLM；
- GEE；
- Cox score；
- inverse probability weighted equations；
- calibration estimators；
- multiple imputation 后联合 estimating equation；
- stacked nuisance/target estimation。

### 8.3 诊断

- 方程是否有唯一根；
- Jacobian 是否可逆；
- score 是否重尾；
- cluster unit 是否正确；
- nuisance plug-in 是否足够快；
- sandwich 中 bread 和 meat 是否按设计构造。

---

## 9. 渐近线性与影响函数

### 9.1 原型

\[
\hat\psi-\psi
=\frac1n\sum_{i=1}^nD(O_i)+o_p(n^{-1/2}),
\quad PD=0.
\]

### 9.2 作用

- 标准误：\(\widehat{Var}(D)/n\)；
- 置信区间；
- robustness 局部诊断；
- one-step correction；
- Bootstrap 一致性；
- 半参数效率。

### 9.3 医学应用

| 参数 | 影响函数用途 |
|---|---|
| 均值/风险 | 基础方差 |
| 分位数 | 非均值结局 |
| AUC | 成对比较依赖 |
| KM 生存率 | 删失结构 |
| 标准化风险 | nuisance 传播 |
| ATE | 双重稳健估计 |
| calibration metric | 模型性能区间 |

### 9.4 失败风险

- 参数不是路径可微；
- influence function 方差无穷；
- positivity 失败；
- nuisance 二阶余项不小；
- 训练与评估未分离。

---

## 10. U 统计量与 Hájek 投影

### 10.1 原型

\[
U_n={n\choose m}^{-1}
\sum h(O_{i_1},\ldots,O_{i_m}).
\]

非退化情况下，U 统计量与其一阶投影渐近等价：

\[
U_n-\theta
=\frac mn\sum_{i=1}^n
\{E[h(O_i,O_2,\ldots,O_m)\mid O_i]-\theta\}
+o_p(n^{-1/2}).
\]

### 10.2 医学应用

- AUC/Mann–Whitney；
- concordance/C-index；
- Kendall tau；
- 成对遗传相似性；
- 二样本秩统计。

### 10.3 常见错误

把所有病例—对照对视为独立，会严重低估方差，因为一个患者参与多个配对。

### 10.4 退化情形

若一阶投影为零，极限通常不是正态，需要高阶谱分解或置换/专门 Bootstrap。

---

## 11. 相邻性与 Le Cam 第三引理

### 11.1 局部备择

\[
\theta_n=\theta_0+h/\sqrt n.
\]

相邻性确保在原假设下概率趋零的事件，在局部备择下也不会突然具有正概率。

### 11.2 第三引理作用

若在 \(P_n\) 下联合收敛

\[
(T_n,\log dQ_n/dP_n),
\]

则可由似然比倾斜得到 \(Q_n\) 下 \(T_n\) 的极限分布。

### 11.3 医学桥接

- 局部功效；
- 非劣效边界附近的检验；
- score 检验备择分布；
- 正则估计量对微小模型扰动的稳定性。

### 11.4 关键边界

局部效应 \(h/\sqrt n\) 是理论缩放，不等于所有临床有意义效应都随样本量缩小。临床意义仍需外部定义。

## 12. LAN 定理

### 12.1 局部似然展开

\[
\log\frac{dP_{\theta_0+h/\sqrt n}^{(n)}}
{dP_{\theta_0}^{(n)}}
=h^T\Delta_n-rac12h^TIh+o_p(1),
\]

\[
\Delta_n\rightsquigarrow N(0,I).
\]

### 12.2 作用

局部上把复杂规则实验近似为高斯位移实验，统一解释：

- MLE 渐近正态；
- Wald/score/LRT 一阶等价；
- 局部最优检验；
- 信息下界；
- 正则估计量定义。

### 12.3 医学失败场景

- 方差分量为 0；
- 稀有混合成分；
- 参数决定支持；
- change-point；
- mixture nonidentifiability；
- complete separation；
- weak instrument；
- boundary probabilities。

此时需非标准极限、profile/penalization、精确或模拟校准。

---

## 13. 卷积定理

### 13.1 结论直觉

规则估计量的极限分布可写成有效正态噪声与额外噪声的卷积：

\[
L=N(0,I^{-1})*M.
\]

因此，信息界对应不可避免的一阶噪声；额外噪声代表低效率。

### 13.2 医学应用

用于比较在同一正确模型和同一 estimand 下的正则估计器效率。

### 13.3 不能做的解释

- 不能说明模型正确；
- 不能比较不同 estimand；
- 不能评价系统偏倚；
- 不能保证有限样本 MSE 最小；
- 不能排除某一点超效率。

---

## 14. 局部渐近极小极大定理

### 14.1 作用

将高斯极限实验的最小风险转为原实验局部邻域中的渐近风险下界。

### 14.2 关键意义

效率应在参数邻域和损失函数下评价，而不是只看真值一点的方差。

### 14.3 医学应用

- 比较连续参数估计器；
- 设计局部备择功效；
- 解释正则化或收缩的局部收益与代价；
- 防止用某一模拟点宣称“全面优越”。

---

## 15. Bernstein–von Mises（BvM）

### 15.1 规则有限维直觉

后验局部近似

\[
\theta\mid X
\approx
N\{\hat\theta_{eff},I(\theta_0)^{-1}/n\}.
\]

### 15.2 作用

解释先验影响减弱、后验摘要一阶等价、可信区间与置信区间接近。

### 15.3 失败风险

- 高维参数增长；
- 半参数目标；
- 非正则/边界；
- 弱识别；
- 不适当或极强先验；
- 模型错设；
- 多峰后验。

### 15.4 医学核查

贝叶斯临床模型应同时做先验敏感性和频率覆盖/决策操作特征模拟，不能只引用 BvM。

---

## 16. Glivenko–Cantelli（GC）类

### 16.1 原型

\[
\sup_{f\in\mathcal F}
|\mathbb P_nf-Pf|	o_p0.
\]

### 16.2 作用

- M 估计一致性；
- 经验风险一致性；
- 数据驱动函数类的统一控制。

### 16.3 医学桥接

当模型包含多个候选阈值、样条、变量或规则时，必须控制整个类，而不是只对最终选中函数使用 LLN。

### 16.4 复杂度

覆盖数、bracketing、VC 维和包络函数用于限制 \(\mathcal F\)。过于灵活的模型可使经验拟合很好却不泛化。

---

## 17. Donsker 定理与经验过程

### 17.1 原型

\[
\mathbb G_n=\sqrt n(\mathbb P_n-P)
\rightsquigarrow G_P
\quad\text{in }\ell^\infty(\mathcal F).
\]

### 17.2 作用

同时控制一个函数类的中心极限定理，为分布函数、score 类、nuisance 依赖统计量和泛函 Delta 提供基础。

### 17.3 医学桥接

- KM 和累计危险过程；
- 时间依赖 ROC；
- 同时置信带；
- 灵活 nuisance 后的插件估计；
- 多阈值诊断性能曲线。

### 17.4 现代扩展

机器学习类往往非 Donsker。cross-fitting 通过样本分割降低对经验过程复杂度的要求，但需要速率和正交性条件。

---

## 18. 泛函 Delta 方法

### 18.1 原型

若

\[
\sqrt n(T_n-\theta)ightsquigarrow G
\]

于函数空间，且 \(\Phi\) Hadamard 可微，则

\[
\sqrt n\{\Phi(T_n)-\Phi(\theta)\}
\rightsquigarrow
\Phi'_\theta(G).
\]

### 18.2 医学应用

- 分位数；
- ROC 曲线；
- 生存函数；
- cumulative incidence；
- standardized survival；
- risk difference 作为分布泛函；
- calibration curve 的函数摘要。

### 18.3 失败风险

- 最大值；
- hard threshold；
- model selection；
- 非唯一分位数；
- 密度在分位点为 0；
- 不连续决策规则。

---

## 19. 分位数渐近正态

若 \(F(q_p)=p\)，且 \(f(q_p)>0\)，则

\[
\sqrt n(\hat q_p-q_p)
\rightsquigarrow
N\left(0,
\frac{p(1-p)}{f(q_p)^2}
\right).
\]

### 医学意义

- 中位生存时间；
- 参考值分位数；
- 检验指标分位点；
- 医疗费用和住院日。

### 风险

尾部密度小、样本量少、删失跨过分位点或分布有平坦区时，正态近似差。中位生存未达到时不能强行报告点估计。

---

## 20. Bootstrap 一致性定理

### 20.1 目标

条件分布

\[
\mathcal L^*\{r_n(T_n^*-T_n)\}
\]

逼近真实抽样分布

\[
\mathcal L\{r_n(T_n-\theta)\}.
\]

### 20.2 典型成功条件

- 统计量正则、渐近线性；
- 参数泛函 Hadamard 可微；
- 重抽样单位正确；
- 极限分布稳定。

### 20.3 典型失败

- 样本最大值；
- 边界；
- cube-root 速率；
- 模型选择；
- 强依赖按行抽样；
- 极端 inverse probability weights。

### 20.4 医学选择

| 数据 | 推荐单位 |
|---|---|
| 独立患者 | 患者 |
| 多次就诊 | 患者 |
| 集群试验 | 集群 |
| 时间序列 | block |
| 分层抽样 | 分层内 |
| 匹配资料 | 匹配集 |

## 21. 切空间与有效影响函数

### 21.1 路径导数

对平滑子模型 \(P_t\) 和 score \(s\)，参数 \(\Psi(P)\) 路径可微若

\[
\left.\frac d{dt}\Psi(P_t)\right|_{t=0}
=P(Ds)
\]

对某个均值为 0 的 \(D\) 成立。

### 21.2 有效影响函数

在所有代表路径导数的影响函数中，位于切空间闭包内且方差最小者为 \(D^*\)。效率下界为

\[
P(D^{*2}).
\]

### 21.3 nuisance 投影

有效 score 为普通 score 减去在 nuisance tangent space 上的正交投影。

### 21.4 医学应用

- ATE；
- missing outcome mean；
- survival under censoring；
- case-control sampling；
- measurement error；
- transportability；
- mediation functionals。

### 21.5 解释边界

EIF 不是某个变量的重要性，而是目标参数对局部分布扰动的梯度代表元。

## 22. One-step 定理

### 22.1 构造

\[
\hat\Psi_{os}
=\Psi(\hat P)+\mathbb P_nD^*(\hat P).
\]

### 22.2 展开

\[
\hat\Psi_{os}-\Psi(P_0)
=(\mathbb P_n-P_0)D^*(P_0)
+R_2(\hat P,P_0)
+o_p(n^{-1/2}).
\]

### 22.3 条件

- \(R_2=o_p(n^{-1/2})\)；
- 影响函数估计稳定；
- positivity；
- 交叉拟合或经验过程条件；
- 方差有限。

### 22.4 医学桥接

AIPW、TMLE 和某些标准化估计器可视为 EIF 驱动的 one-step/targeted 更新。

---

## 23. 双重稳健余项

以缺失结局或 ATE 为例，二阶余项常有乘积形式：

\[
R_2
\approx
\int
(\hat g-g_0)(\hat Q-Q_0)w\,dP_0.
\]

若 \(\hat g\) 或 \(\hat Q\) 至少一个一致，估计可能一致；若两者误差乘积为 \(o_p(n^{-1/2})\)，可实现 \(\sqrt n\) 推断。

### 关键限制

- 两模型同时错设时无保护；
- positivity 失败会放大误差；
- 双重稳健不等于双倍精确；
- 高维 nuisance 仍需速率与交叉拟合。

## 24. 定理到方法的映射表

| 方法 | 主要理论 | 关键失败 |
|---|---|---|
| t/ANOVA | 正态有限样本、投影 | 非独立、异方差处理错误 |
| GLM MLE | M/Z、LAN、信息 | 分离、边界、错设 |
| GEE | Z 估计、cluster CLT | 聚类数少、相关单位错 |
| Cox | score、martingale/半参数 | 非比例风险、删失依赖 |
| KM | 经验过程、泛函 Delta | informative censoring |
| AUC | U 统计量 | 成对依赖忽略 |
| Quantile | 泛函 Delta | 密度近 0、非唯一分位数 |
| Bootstrap | 条件弱收敛 | 非正则、错误抽样单位 |
| Penalized model | M 估计、经验过程 | 选择后推断、调参泄漏 |

## 25. 有限样本模拟模板

```r
simulate_once <- function(n, scenario, seed = NULL) {
  if (!is.null(seed)) set.seed(seed)

  dat <- generate_data(n = n, scenario = scenario)
  fit <- try(fit_method(dat), silent = TRUE)

  if (inherits(fit, "try-error")) {
    return(data.frame(
      estimate = NA_real_,
      se = NA_real_,
      cover = NA,
      reject = NA,
      converged = FALSE
    ))
  }

  est <- extract_estimate(fit)
  se  <- extract_se(fit)
  ci  <- est + c(-1, 1) * qnorm(0.975) * se

  data.frame(
    estimate = est,
    se = se,
    cover = ci[1] <= scenario$truth && scenario$truth <= ci[2],
    reject = abs(est / se) > qnorm(0.975),
    converged = TRUE
  )
}
```

正式模拟还应记录 warning、边界、权重极端、运行时间和 Monte Carlo SE。

## 26. 定理审查模板

对论文中的每个“由渐近理论可得”，逐项询问：

1. 随机序列是什么；
2. 极限中 \(n\) 如何增加；
3. 独立单位是什么；
4. 参数是否可识别且位于内部；
5. 准则或 score 是否可微；
6. Jacobian/信息矩阵是否非奇异；
7. 余项为何是 \(o_p(n^{-1/2})\)；
8. nuisance 估计速率是多少；
9. 是否需要统一收敛或 Donsker；
10. 当前样本下覆盖率是否通过模拟验证。

## 27. 精通层结论

1. 大数定律提供稳定中心，中心极限定理提供随机主项，Delta 方法传递尺度，Slutsky 允许一致代入；四者构成最基础的近似链。
2. M/Z 估计的关键不是求解器，而是一致性、可线性化、非奇异导数和随机主项。
3. LAN 把局部规则模型转为高斯实验，效率和局部功效由此获得统一解释。
4. U 统计量、经验过程和泛函 Delta 处理的是超出普通样本均数的统计对象，是 AUC、生存函数、分位数和曲线推断的基础。
5. Bootstrap 的正确性是定理，不是重抽样次数；非正则统计量和错误重抽样单位会使其系统失败。
6. 半参数理论通过切空间和正交投影隔离 nuisance 方向，EIF 同时编码估计、方差、效率和稳健修正。
7. 医学统计专家需要把每个抽象条件翻译成真实数据问题：患者是否独立、删失是否可忽略、权重是否稳定、参数是否在边界、变量是否在预测时可用、模型是否可识别。
8. 真正掌握渐近理论的标志，是能在方法失效前识别失效机制，并选择精确法、模拟校准、替代 estimand、稳健估计或重新设计研究，而不是机械引用“样本量足够大”。
